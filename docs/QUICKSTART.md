# 3 分钟上手

从下载到第一次成功切号。全程不需要命令行，也不需要管理员权限。

> 平台：**Windows 10 / 11 (x64)**，以及 **Linux x64**（AppImage / deb，CentOS 7 除外，
> 见下方说明）。非官方第三方工具，使用前请先读 [免责声明](policies/DISCLAIMER.md)。

---

## 0. 先确认前置条件（约 20 秒）

- Windows 10 1809 及以上，或 Windows 11，64 位；
  或 Linux x64（Ubuntu 20.04+ / Debian 11+ / CentOS 8+）。
  **CentOS 7 的 glibc 2.17 跑不起桌面包**，只能用源码跑后端，见
  [桌面端说明](../desktop/README.md#centos-用户先读这一段)；
  完整步骤在 [Linux 部署](LINUX.md)。服务器上长期运行（退出 SSH 也不停）见
  [常驻运行](LINUX.md#b4-常驻运行systemd---user服务器场景)。
- 至少装过一个客户端：WorkBuddy 国内版或 Trae 国内版，且能正常登录。
- 切号会重启目标客户端：**切换前请自己退出它**。工具检测到客户端仍在运行时会拒绝写入，
  这是保护，不是故障。

---

## 1. 下载并安装（约 40 秒）

1. 到 [Releases](https://github.com/Chaierss/workbuddy-trae-assist/releases) 下载最新版：
   - Windows：`chaierww-Setup-<版本号>.exe`，双击安装。默认只装给当前用户、免管理员，
     向导会先展示许可要点与免责声明。
   - Linux：`chaierww-x64.AppImage` 或 `chaierww-x64.deb`。
     AppImage 先 `chmod +x` 再双击 / 运行；缺 FUSE 时用
     `APPIMAGE_EXTRACT_AND_RUN=1 ./chaierww-x64.AppImage`。
     deb 用 `sudo apt install ./chaierww-x64.deb`（Debian / Ubuntu）。
2. 首次启动 Windows 会拦一次（安装包没有代码签名）：点「更多信息 → 仍要运行」。
   Linux 桌面首次运行 AppImage 可能需要允许「执行」权限。

装完托盘常驻，关掉窗口不会退出程序（Linux 托盘需要 `libappindicator` / `gir1.2-appindicator3`）。

---

## 2. 扫码加号（约 40 秒）

打开应用 → 「号池」→ **WorkBuddy 扫码**（或 **Trae 扫码**）→ 用客户端扫一下。

已经有登录态的账号，还有两条更快的路：

- **一键入池**：客户端当前已登录的账号，概览页会直接提示入池。
- **JSON 导入**：把登录态文件拖进导入框，平台自动识别；本工具自己导出的
  `chaierww-accounts-*.json` 也能整包恢复。

号池里出现账号，就完成第一步了。

---

## 3. 先预演，再切换（约 30 秒）

1. 在目标账号卡片上点 **切换**。第一次会先打开预演结果：这次会迁移多少会话、
   会改动哪些配置、哪些项目不支持。
2. 确认无误后点 **继续切换**。工具会先强制备份，再原子写入，最后校验；
   任何一步失败都会自动回滚到切换前。
3. 成功后客户端会自动重启到目标账号。第一次切换成功后，界面会给一次「下一步」提示：
   开每日签到、签发网关 Key，或直接关掉。

**中途想反悔**：切换前会自动生成一份备份，可在「设置 → 备份」里恢复。

---

## 4. 常见失败与处理

| 现象 | 原因 | 处理 |
|:--|:--|:--|
| 安装时被 SmartScreen 拦住 | 安装包没有代码签名 | 点「更多信息 → 仍要运行」 |
| 切换按钮灰色，提示客户端正在运行 | 客户端未退出，工具不做边跑边改 | 手动退出客户端后重试 |
| 切完客户端没起来 | 客户端路径不对，或客户端正在更新 | 「设置 → 环境」核对登录目录；手动双击图标确认客户端正常 |
| 提示「需重新登录」 | 上游返回 401，凭据已失效 | 重新扫码登录该账号；失败计数会自动清零 |
| 提示「凭据不完整」 | 扫码登录的号没有明文 refresh token（平台不提供） | 现在能切号；token 过期后重新扫码即可，不是故障 |
| 打开页面显示端口被占用 | 本机 API 端口冲突 | 关掉占用端口的进程，或在「设置 → 环境」查看当前服务地址 |
| 积分显示「不可查」 | 该账号凭据不含积分查询所需字段 | 属正常降级，不影响切号与活动 |

---

## 5. 接下来可以做什么

- **活动**：官方活动目录写清规则与奖励；能自动的一键跑完，手动的写明卡在哪。
- **用量**：请求与积分按模型、按日归集，能看出哪个号快用完。
- **额度网关**：把账号额度开成 OpenAI / Anthropic 兼容接口，借给本机其它 AI 工具。
- **设置 → 备份 / 环境**：每日自动备份、会话同步、体验数据都在这里。

---

## 数据在哪

全部在 `~/.chaierww`（可用环境变量 `CHAIERWW_HOME` 覆盖）：SQLite 库、加密后的凭据、
备份与脱敏日志。**不上云、不中转**。想迁移整台机器，拷走这个目录即可。

本地体验数据（首次成功换号率之类的匿名计数）默认**只写本机**，
可在「设置 → 环境 → 体验数据」关闭、导出或一键清空，详见
[本地体验数据说明](policies/TELEMETRY.md)。
